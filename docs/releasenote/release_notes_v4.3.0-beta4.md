## 🚀 LeanType 4.3.0-beta4

---

### ✨ Features & Improvements
- **Chinese Punctuation & CJK Symbols Layout**: Integrated full-width Chinese punctuation (comma, period, question mark, exclamation, colon, semicolon), added a dedicated CJK symbols layout, and enabled real-time preedit sync with the CJK plugin.
- **Offline AI Long Text Scaling**: Dynamically scaled maximum generation tokens based on input length (up to 1,536 tokens) and expanded the context buffer to 3,072 tokens, preventing truncated outputs when proofreading long paragraphs.
- **Blocked Words Import & Export (#687)**: Added standalone import and export for blocked words with support for plain word lists, language tags, comments, and automatic duplicate filtering.
- **Update Notification Badging Scope**: Scoped update red dot indicators specifically to the Updates section and keyboard updater to reduce clutter across other settings categories.
