LeanType 是一款快速、注重隐私且高度可定制的 Android 开源键盘，基于 AOSP 和 HeliBoard 的坚实基础构建。专为流畅输入、出色的人体工程学设计和模块化生产力打造，让您在完全不被收集任何数据的前提下掌控键盘体验。

<b>🛡️ 隐私优先与纯离线运行:</b>
<ul>
  <li><b>100% 开源透明:</b> 无任何遥测、无广告、无后台追踪。</li>
  <li><b>严格数据安全:</b> 您的所有击键记录和个人数据仅保存在本机。</li>
  <li><b>零敏感权限:</b> 无需通讯录、位置等任何侵犯隐私的权限。</li>
</ul>

<b>⌨️ 人体工学与流畅输入:</b>
<ul>
  <li><b>滑行手势输入:</b> 丝滑滑动输入，支持自定义灵敏度与轨迹。</li>
  <li><b>多语言支持:</b> 智能自动更正、预测联想以及 Gboard 词库一键导入。</li>
  <li><b>空格触控板与文本编辑:</b> 滑动空格键移动光标，并配备独立 DPAD 文本编辑面板以进行精准选择。</li>
  <li><b>悬浮键盘:</b> 原生可拖动与缩放的悬浮窗口，多任务协作更轻松，无需悬浮窗系统权限。</li>
  <li><b>单手与分屏模式:</b> 针对大屏手机、折叠屏和平板电脑优化。</li>
  <li><b>外接硬件键盘:</b> 完美支持蓝牙与 USB 实体键盘候选词选择及自动更正。</li>
</ul>

<b>🎨 深度定制与触感音效:</b>
<ul>
  <li><b>Material You 与主题:</b> 动态系统取色、深色/浅色模式、支持高斯模糊自定义壁纸背景。</li>
  <li><b>按键细节调优:</b> 字母键、功能键、动作键独立圆角曲率调整与间隙控制。</li>
  <li><b>机械键盘音效:</b> 超低延迟音频引擎，内置 Cherry MX、复古打字机、复古 CRT 等丰富音效包。</li>
</ul>

<b>⚡ 剪贴板与生产力工具:</b>
<ul>
  <li><b>智能剪贴板管理:</b> 实时搜索、工具栏直接内联编辑、置顶收藏与误删 5 秒撤销。</li>
  <li><b>内联数学计算器:</b> 直接输入算式（例如 25*4= 或 150-20%=）即可在候选栏秒出答案。</li>
  <li><b>动态文本扩展:</b> 快捷短语支持日期、时间与剪贴板等动态变量插入。</li>
  <li><b>截图智能提示:</b> 截屏后自动弹出快捷药丸，支持一键分享与文字提取。</li>
  <li><b>分类备份与还原:</b> 按需单独备份或恢复布局、主题、词库与剪贴板。</li>
</ul>

<b>🧩 模块化输入扩展:</b>
<ul>
  <li><b>离线语音输入:</b> 基于本地 Whisper 模型的离线高精度语音转文字。</li>
  <li><b>手写识别:</b> 键盘自带书写板，直接手写汉字与符号。</li>
  <li><b>相机与截图 OCR:</b> 无需跳出应用，直接在键盘内置取景器中提取文字。</li>
  <li><b>内置快速翻译:</b> 支持离线模型与云端 API 即时翻译。</li>
</ul>

<b>🤖 智能 AI 助手 (完全自选):</b>
<ul>
  <li><b>按需语法与润色:</b> 随时润色、纠错或调整语言语气风格。</li>
  <li><b>丰富模型接入:</b> 自由连接 Google Gemini、Groq、OpenAI 或本地私有化大模型 (Ollama, LM Studio)。</li>
  <li><b>自定义 AI 按键:</b> 工具栏支持绑定个性化提示词 (Prompt)。</li>
  <li><b>严守主动触发原则:</b> 仅在您主动配置 API Key 并点击请求时才会联网。</li>
</ul>
