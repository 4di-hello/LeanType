LeanType は、AOSP と HeliBoard の安定した基盤の上に構築された、高速でプライバシーを最優先にした高度にカスタマイズ可能な Android 向けオープンソースキーボードです。滑らかなタイピング、人間工学に基づいた操作性、そしてモジュール式の生産性向上機能を、一切のデータ収集なしで提供します。

<b>🛡️ プライバシー＆完全オフライン重視:</b>
<ul>
  <li><b>100% オープンソース:</b> テレメトリ、広告、バックグラウンドでの追跡は一切ありません。</li>
  <li><b>データ保護:</b> 入力内容や個人データは端末内にのみ安全に保存されます。</li>
  <li><b>センシティブ権限不要:</b> 連絡先や位置情報などの不要な権限は一切要求しません。</li>
</ul>

<b>⌨️ 人間工学と快適なタイピング:</b>
<ul>
  <li><b>ジェスチャー入力:</b> 感度と軌跡表示を調整できるスムーズなスワイプ入力。</li>
  <li><b>多言語サポート:</b> 自動修正、単語予測、Gboard 辞書のインポートに対応。</li>
  <li><b>トラックパッドカーソルと編集機能:</b> スペースバーをなぞってカーソル移動、専用 DPAD パネルで正確な範囲選択が可能。</li>
  <li><b>フローティングキーボード:</b> システムオーバーレイ権限なしで使える、ドラッグ＆リサイズ可能なマルチタスク対応ウィンドウ。</li>
  <li><b>片手モード＆分割キーボード:</b> スマートフォン、折りたたみ端末、タブレットに最適化。</li>
  <li><b>ハードウェアキーボード対応:</b> Bluetooth や USB の物理キーボードでも予測変換と自動修正が機能。</li>
</ul>

<b>🎨 自由なカスタマイズ＆キータッチ音:</b>
<ul>
  <li><b>Material You とテーマ:</b> システム動的カラー、ダーク/ライトテーマ、ぼかし効果付きの壁紙背景に対応。</li>
  <li><b>キーの細部調整:</b> 通常キー、機能キー、アクションキーの角丸半径やキー間隔を個別に調整可能。</li>
  <li><b>心地よい打鍵音:</b> Cherry MX、タイプライター、レトロ CRT など、低遅延サウンドパックを内蔵。</li>
</ul>

<b>⚡ クリップボード＆生産性ツール:</b>
<ul>
  <li><b>スマートクリップボード:</b> 履歴検索、ツールバーでの直接編集、ピン留め、5秒間の削除取り消しに対応。</li>
  <li><b>インライン計算機:</b> 式を入力するだけ（例: 25*4= や 150-20%=）で候補欄に即座に答えを表示。</li>
  <li><b>テキスト展開:</b> 日付、時刻、クリップボードの内容を挿入できる便利な短縮登録。</li>
  <li><b>スクリーンショット提案:</b> 撮影したスクリーンショットから1タップで共有や文字起こしが可能。</li>
  <li><b>カテゴリ別バックアップ:</b> レイアウト、テーマ、辞書、履歴を選択して個別にバックアップ＆復元。</li>
</ul>

<b>🧩 プラグインによる入力拡張:</b>
<ul>
  <li><b>音声入力:</b> Whisper モデルを活用した、高精度なオンデバイス音声認識。</li>
  <li><b>手書き文字入力:</b> キーボード上のキャンバスに直接文字や記号を手書き入力。</li>
  <li><b>カメラ＆スクリーンショット OCR:</b> 内蔵カメラファインダーから書類のテキストを即座に抽出。</li>
  <li><b>キーボード内翻訳:</b> オフラインモデルやクラウドサービスを用いたスムーズな翻訳。</li>
</ul>

<b>🤖 スマート AI ツール (完全任意):</b>
<ul>
  <li><b>オンデマンド推敲:</b> 文法チェック、表現の言い換え、トーン調整を必要なときだけ利用。</li>
  <li><b>自由なプロバイダー選択:</b> Google Gemini、Groq、OpenAI、ローカル LLM (Ollama, LM Studio) に接続可能。</li>
  <li><b>カスタム AI キー:</b> よく使うプロンプトをツールバーのキーに登録。</li>
  <li><b>安心の利用形態:</b> API キーを設定し、ボタンをタップした時のみ通信を行います。</li>
</ul>

LeanBitLab が ❤️ を込めて開発。
