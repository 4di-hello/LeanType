LeanType - це швидка, приватна та гнучка клавіатура з відкритим вихідним кодом для Android, створена на основі AOSP та HeliBoard. Створена для плавного набору тексту, чудової ергономіки та модульної продуктивності, LeanType надає повний контроль без збору персональних даних.

<b>🛡️ Приватність та автономна робота:</b>
<ul>
  <li><b>100% Відкритий код:</b> Жодної телеметрії, реклами чи фонового стеження.</li>
  <li><b>Захист даних:</b> Ваші натискання клавіш та інформація зберігаються лише на вашому пристрої.</li>
  <li><b>Жодних небезпечних дозволів:</b> Працює без доступу до контактів, геопозиції чи інших вразливих дозволів.</li>
</ul>

<b>⌨️ Ергономіка та зручний набір:</b>
<ul>
  <li><b>Неперервне введення (свайп):</b> Плавний набір жестами з налаштуванням чутливості та сліду.</li>
  <li><b>Багатомовна підтримка:</b> Автовиправлення, підказки слів та імпорт словників з Gboard.</li>
  <li><b>Керування курсором та редагування:</b> Проведіть по пробілу для руху курсору або використовуйте панель зі стрілками DPAD для точного виділення тексту.</li>
  <li><b>Плаваюча клавіатура:</b> Зручне вікно з можливістю переміщення та зміни розміру без системних дозволів.</li>
  <li><b>Режими для однієї руки та розділення:</b> Адаптовані розкладки для смартфонів, планшетів і складаних екранів.</li>
  <li><b>Апаратні клавіатури:</b> Підтримка підказок та автокорекції для зовнішніх Bluetooth та USB клавіатур.</li>
</ul>

<b>🎨 Персоналізація та звуки клавіш:</b>
<ul>
  <li><b>Material You та теми:</b> Динамічні системні кольори, світлі/темні теми та фонові шпалери з розмиттям.</li>
  <li><b>Ергономіка клавіш:</b> Окреме налаштування заокруглення кутів клавіш і відстані між ними.</li>
  <li><b>Приємний звук клацання:</b> Аудіомодуль із низькою затримкою: Cherry MX, друкарська машинка, ретро CRT та власні пакети звуків.</li>
</ul>

<b>⚡ Буфер обміну та інструменти:</b>
<ul>
  <li><b>Розумний буфер обміну:</b> Пошук, редагування безпосередньо на панелі, закріплення та скасування видалення за 5 секунд.</li>
  <li><b>Вбудований калькулятор:</b> Вводьте математичні вирази (наприклад, 25*4= або 150-20%=), щоб побачити відповідь у рядку підказок.</li>
  <li><b>Розширення тексту:</b> Зручні скорочення зі змінними дати, часу та буфера обміну.</li>
  <li><b>Підказки скриншотів:</b> Витягуйте текст або діліться свіжими знімками екрана в один дотик.</li>
  <li><b>Модульне резервне копіювання:</b> Вибірковий експорт та імпорт розкладок, тем, словників та історії.</li>
</ul>

<b>🧩 Модульні плагіни введення:</b>
<ul>
  <li><b>Голосовий ввід:</b> Точне локальне розпізнавання мови за допомогою моделей Whisper без інтернету.</li>
  <li><b>Рукописне введення:</b> Малювання літер та символів прямо на панелі клавіатури.</li>
  <li><b>OCR сканування тексту:</b> Розпізнавання тексту з паперових документів або знімків екрана.</li>
  <li><b>Переклад у клавіатурі:</b> Миттєвий переклад через автономні моделі або хмарні сервіси.</li>
</ul>

<b>🤖 Інструменти штучного інтелекту (За бажанням):</b>
<ul>
  <li><b>Перевірка тексту за запитом:</b> Виправляйте граматику, змінюйте тон або перефразовуйте речення коли потрібно.</li>
  <li><b>Широкий вибір провайдерів:</b> Підключення до Google Gemini, Groq, OpenAI або локальних моделей (Ollama, LM Studio).</li>
  <li><b>Власні клавіші AI:</b> Призначайте індивідуальні запити на клавіші панелі інструментів.</li>
  <li><b>Повна прозорість:</b> Мережа використовується тільки за наявності вашого ключа API і лише за вашою прямою дією.</li>
</ul>
